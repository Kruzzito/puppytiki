# Puppytiki - Gestión Veterinaria y Civil de Mascotas

### [Disponible en Google Play Store] (https://play.google.com/store/apps/details?id=com.mixtecostudio.puppytikiv1&hl=es_MX)

## Sobre el Proyecto
**Puppytiki** es una aplicación móvil híbrida diseñada para centralizar la gestión de mascotas. No es solo una agenda; es una herramienta administrativa que permite la creación de documentos oficiales y la integración con ecosistemas comerciales y educativos.

## Tecnologías y Arquitectura
- **Framework:** Angular & Ionic (Despliegue multiplataforma).
- **Lógica de Documentos:** Motor de generación dinámica de PDFs (Actas, Carnets, Credenciales).
- **Integraciones de API:** - **YouTube:** Streaming de contenido educativo especializado.
    - **Mercado Libre:** Sincronización de productos para una experiencia de e-commerce integrada.
- **Gestión de Datos:** Sistema de agenda optimizado para usuarios multimascota.

## Características Técnicas Destacadas
- **Arquitectura Modular:** Separación clara entre servicios de API, lógica de PDF y componentes de interfaz.
- **UX/UI Especializada:** Diseño pensado en la facilidad de uso para dueños de mascotas y profesionales.
- **Sincronización:** Consumo de servicios externos para mantener información de productos actualizada en tiempo real.

## Estructura del Código
El repositorio contiene el núcleo lógico desarrollado en Angular, incluyendo:
- Servicios personalizados para comunicación con APIs.
- Pipes y directivas para el manejo dinámico de documentos.
- Configuración de Capacitor para despliegue nativo en Android.
